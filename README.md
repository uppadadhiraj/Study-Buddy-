# 📚 Study Buddy

Study Buddy is an AI-based study assistant that helps students study from their own PDF notes and study materials.

The main idea of this project is to create different subjects and upload study material for each subject. The AI then answers questions based on the study material uploaded for that particular subject.

For example, if I select **Physics**, the AI will only search the PDFs that were uploaded under Physics. It will not use the PDFs from DBMS or Chemistry.

---

## 💡 Idea Behind the Project

While studying, students usually have notes and PDFs for different subjects. Searching through all these PDFs to find an answer can take a lot of time.

So I wanted to build a simple AI study assistant where:

- Students can create their own subjects.
- Students can upload PDFs for a particular subject.
- Students can ask questions about that subject.
- The AI searches the uploaded study material and gives an answer.
- Information from other subjects is not used.
- The user can choose how detailed the answer should be.
